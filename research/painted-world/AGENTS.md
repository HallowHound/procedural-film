# Painted-world R&D boundary

Preserve all existing products. This folder explicitly permits **licensed or
user-authorized media assets**; the original zero-assets restriction is not the art
strategy here. Never commit the supplied illustration or generated derivatives by
default. Read README.md and docs/CODEX_MISSION.md before changing scope.

The browser study is diagnostic. Do not extend it into another cutout wallpaper
and call that the requested travelling 3D world. Production must pass a real-3D
camera and character-contact vertical slice. No hour render before art acceptance.
No inference in the render loop. Reuse canonical assets. Keep documents in English.
Keep tasks bounded to a subsystem, not one agent or thousands of drawing lines per
shot. Report measurements and missing capabilities; never self-certify visual
quality from a green technical test. Preserve failed experimental findings.
